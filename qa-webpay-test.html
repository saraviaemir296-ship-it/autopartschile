QA Webpay Plus — Página de uso interno (no indexada, no enlazada en el sitio)

Esta página NO es para clientes. Sirve solo para que Emir complete manualmente las pruebas de tarjeta que Transbank exige para la validación (evidencia). Ambiente: INTEGRACIÓN (ninguna tarjeta real puede ser cobrada aquí).

Paso 1. Presiona el botón. Se creará una transacción de prueba real ($29.990, mismo SKU usado en pruebas anteriores) y te llevará a la pantalla real de Transbank.

Paso 2. En la pantalla de Transbank, elige "Tarjetas" e ingresa UNA de estas tarjetas de prueba oficiales (nunca una tarjeta real):

  • Aprobada (crédito/débito): 4051 8856 0044 6623 — CVV 123 — cualquier fecha de vencimiento futura.
  • Rechazada (crédito/débito): 5186 0595 5959 0568 — CVV 123 — cualquier fecha de vencimiento futura.

Si te pide autenticación bancaria (Redcompra/débito), usa RUT 11.111.111-1 y clave 123.

Paso 3. Repite este proceso una vez por cada tarjeta que necesites probar (aprobada y rechazada son transacciones separadas — vuelve a esta página y presiona el botón de nuevo para cada una).
